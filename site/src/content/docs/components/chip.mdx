```tsx
// Web: React, consuming @dizyx/nockerl-tokens. (Web is the laggard platform; this is the
// canonical API the published @dizyx/nockerl-react package is intended to expose. It
// unifies both shipped idioms: `selected` for filtering, `onRemove` for removable tokens.)
import { NockerlChip } from '@dizyx/nockerl-react';

export function FilterStrip() {
  const [active, setActive] = useState('sessions');
  return (
    <div className="chip-row">
      {/* filter idiom: selected gets the cyan fill */}
      <NockerlChip text="Sessions" selected={active === 'sessions'} onClick={() => setActive('sessions')} />
      <NockerlChip text="Agents" selected={active === 'agents'} onClick={() => setActive('agents')} />

      {/* input idiom, a removable token */}
      <NockerlChip text="typescript" selected onRemove={() => removeTag('typescript')} />
    </div>
  );
}
```

// Ships the SELECTABLE (filter) idiom: a pill that toggles selected/unselected.
import com.dizyx.nockerl.design.components.NockerlChip
import com.dizyx.nockerl.design.components.NockerlStatusDot
import com.dizyx.nockerl.design.components.NockerlStatusDotStatus

NockerlChip(
    text = "Sessions",
    onClick = { active = "sessions" },
    selected = active == "sessions",
)
NockerlChip("Agents", onClick = { active = "agents" }, selected = active == "agents")

// optional leading content (e.g. a status dot)
NockerlChip(
    text = "Online",
    onClick = ::toggleOnline,
    selected = true,
    leadingContent = { NockerlStatusDot(status = NockerlStatusDotStatus.SUCCESS) },
)

<Aside type="note" title="Selectable only, no removable variant">
The published `NockerlChip` is **selectable only** on both native platforms. There is no
trailing-✕ / `onRemove` parameter. A removable/tag chip is a web-only capability today; on
Android or Swift it would be a custom composition. Tracked in the drift note.
</Aside>

<Aside type="note" title="Cross-platform parity (published packages)">
The published **Compose** (`com.dizyx.nockerl.design.components`) and **Swift**
(`NockerlDesign`) `NockerlChip` now share the selectable idiom and the pill token, and the
earlier drift is resolved:

- **Same idiom.** Both native platforms ship the **selectable** chip (`selected`, no ✕).
  Swift's old removable-only `Chip` is retired. The removable/tag chip is now a web-only
  capability.
- **Pill radius is tokenized.** Swift consumes `NockerlRadius.pill`; Compose uses
  `NockerlPillShape`. Same fully-rounded silhouette from a shared token, no bare `Capsule()`.
- **Disabled is honored.** Swift dims via `.disabled(_:)` (environment); Compose via the
  explicit `enabled` + 0.38 alpha.

Remaining, intentional differences:

- **Selected fill treatment.** Compose's selected chip is a **solid** `accentPrimary` +
  contrast label; Swift's selected chip is the soft `accentPrimarySoft` wash + cyan label.
  Both are token-driven static fills, a deliberate per-platform read of the selection wash.
- **Leading content.** Compose exposes a `leadingContent` slot (e.g. a status dot); web has
  `leadingIcon`; the published Swift `NockerlChip` has no leading slot yet.
</Aside>
