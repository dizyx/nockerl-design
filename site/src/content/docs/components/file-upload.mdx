```kotlin
// Android Jetpack Compose (canonical). The shipped app attaches IMAGES only via
// the system photo picker; there is no dropzone / size / per-file progress yet.
import androidx.activity.compose.rememberLauncherForActivityResult
import androidx.activity.result.PickVisualMediaRequest
import androidx.activity.result.contract.ActivityResultContracts

val picker = rememberLauncherForActivityResult(
    contract = ActivityResultContracts.PickMultipleVisualMedia(maxItems = 8),
) { uris -> viewModel.attach(uris) }

NockerlIconButton(
    icon = Icons.Filled.AttachFile,
    contentDescription = "Attach",
    onClick = {
        picker.launch(
            PickVisualMediaRequest(ActivityResultContracts.PickVisualMedia.ImageOnly),
        )
    },
)
```

```swift
// macOS SwiftUI (canonical). Nockerl Voice ships NO file affordance today; this

.fileImporter(
    isPresented: $showImporter,
    allowedContentTypes: [.plainText, .json, .yaml, .image],
    allowsMultipleSelection: true,
) { result in
    if case .success(let urls) = result { uploader.add(urls) }
}
.dropDestination(for: URL.self) { urls, _ in
    uploader.add(urls)
    return true
}
```

<Aside type="caution" title="Cross-platform drift (tracked for reconciliation)">
The dropzone, file list, per-file progress, and success / error / rejected states
are **web-only** today, designed originally from the laws + the Button / TextField
/ progress vocabulary, since the apps don't ship them:

- **Android** attaches **images only** through the system photo picker
  (`PickMultipleVisualMedia`) and shows dismissable thumbnail chips (an X in the
  error color). No generic files, no size, no drag-drop, no per-file progress.
- **Voice (macOS)** ships **no** file affordance at all; the Swift code/params
  above are the intended `.fileImporter` + `.dropDestination` API.
- The signature **dropzone** reuses the recessed-well + dashed-border look from the
  text field; the **progress bar** reuses the gauge track; **browse/upload** reuse
  the button ladder, so when the apps adopt it, it already matches.
</Aside>
