The **web console's ambient strip**: branch, agent/job state,
cursor position, keyboard hints. All of it is reading-scale CHROME, deliberately **not**
the [`Toolbar`](/components/toolbar/)'s control-scale grammar. Segments are quiet spans by
default; give one `onSelect` and it becomes a real button (hover wash + ink + focus
outline); nothing looks pressable unless it is. State rides the shared
[`StatusDot`](/components/status-dot/) ladder; hints are real [`Kbd`](/components/kbd/)
keycaps.

<DocCallout tone="note" title="Web-only by scope">
Native consoles have no equivalent surface, so this ships web-only (on the shared
tokens and laws, no cross-platform spec needed).
</DocCallout>
