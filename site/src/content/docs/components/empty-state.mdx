```kotlin
// Android: Jetpack Compose (canonical). The shipped pattern is a centered Column
// (a 48dp muted icon → bodyMedium message → optional NockerlButton), e.g.
// files/ui/FilesSheet.kt, inbox/ui/InboxSheet.kt, chat/ui/MessageList.kt.
import androidx.compose.foundation.layout.*
import androidx.compose.material3.Icon
import androidx.compose.material3.Text
import androidx.compose.ui.Alignment
import com.nockerl.app.core.ui.NockerlButton
import com.nockerl.app.core.ui.NockerlButtonVariant

@Composable
fun EmptyState(
    icon: ImageVector,
    title: String,
    description: String? = null,
    action: (@Composable -> Unit)? = null,
) {
    val colors = LocalNockerlColors.current
    Column(
        modifier = Modifier.fillMaxSize(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center,
    ) {
        Icon(icon, contentDescription = null, modifier = Modifier.size(48.dp), tint = colors.onCardAltMuted.copy(alpha = 0.5f))
        Spacer(Modifier.height(16.dp))
        Text(title, style = MaterialTheme.typography.titleMedium, color = colors.onCard)
        description?.let {
            Spacer(Modifier.height(4.dp))
            Text(it, style = MaterialTheme.typography.bodyMedium, color = colors.onCardAltMuted)
        }
        action?.let { Spacer(Modifier.height(16.dp)); it() }
    }
}

// Failed-to-load: pass a Retry as the action.
EmptyState(Icons.Filled.FolderOpen, "Couldn't load files", "Check your connection and try again.") {
    NockerlButton(text = "Retry", onClick = ::reload, variant = NockerlButtonVariant.TERTIARY)
}
```

<Aside type="caution" title="Cross-platform drift (tracked for reconciliation)">
The web spec is in review; the shipped platforms diverge on the empty-state primitive:

- **No shared component.** Android hand-rolls a centered `Column` per screen (no
  `NockerlEmptyState` yet); Voice uses the **system** `ContentUnavailableView`;
  web is unshipped. The Compose pattern above should be promoted to a real
  `core/ui` composable so all empties match.
- **Icon language** *(resolved in [adjudication 2026-07-02 · B17])*: empty-state illustrations are
  **our stroke-SVG brand set on all platforms** (the web's token-colored inline strokes); utility
  glyphs stay platform-native (Material / SF). Android's `ImageVector` tint and Voice's SF Symbols
  give way to the shared brand set for the illustration slot.
- **CTA support.** Android + web allow an action (Retry / Create); Voice's empties
  ship **text-only** (no action on the short `ContentUnavailableView`). Use the
  closure form when an action is needed.
- **Title role.** Web/Android settle on `title.medium/large`; the chat/no-session
  arm on Android still uses `displayMedium` + a wordmark, which is out of scope for
  the generic empty state.
</Aside>
