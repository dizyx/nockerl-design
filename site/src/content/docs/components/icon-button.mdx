<DocCallout tone="note" title="Cross-platform parity (published packages)">
The published **Compose** (`com.dizyx.nockerl.design.components`) and **Swift**
(`NockerlDesign`) packages now share both idioms and the a11y contract. The earlier drift
is resolved:

- **Both idioms ship.** Swift has `.plain` **and** `.filledCircle` (the send/stop slot),
  matching Compose/web, no longer plain-only.
- **Control radius is tokenized.** The `.plain` idiom consumes `NockerlRadius.control`
  (**12pt**); `.filledCircle` uses the pill radius. The hardcoded 10pt is gone.
- **Hit target meets the minimum.** Swift renders a **40pt visual inside a ≥44pt hit frame**
  (Apple HIG), matching Compose's 40dp default. The old 24×22pt frame is gone.
- **Accessible name is required.** Swift's `label` is now a required, non-empty argument that
  asserts in debug, matching Compose's `contentDescription` / web's `label`. No more unnamed
  default.

Remaining, minor differences:

- **Sizing knob:** Compose/web expose an explicit `size` (and Compose `iconSize`); Swift's
  visual is fixed at 40pt (the shared control height). Disabled state is honored via
  `.disabled(_:)` on Swift rather than an `enabled` parameter.
</DocCallout>
