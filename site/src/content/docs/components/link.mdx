```kotlin
// Android: Jetpack Compose (canonical). There is no bespoke NockerlLink composable
// yet: chat/ui/MarkdownContent.kt renders links through the markdown renderer, which
// styles them via Compose's TextLinkStyles + LinkAnnotation + UriHandler. This is that
// underlying primitive, bound to the single cyan brand accent + an underline.
import androidx.compose.material3.Text
import androidx.compose.ui.text.LinkAnnotation
import androidx.compose.ui.text.SpanStyle
import androidx.compose.ui.text.TextLinkStyles
import androidx.compose.ui.text.buildAnnotatedString
import androidx.compose.ui.text.style.TextDecoration
import androidx.compose.ui.text.withLink

val accent = NockerlTheme.colors.accentPrimary   // brand cyan, the only link color
val linkStyles = TextLinkStyles(
    style = SpanStyle(color = accent, textDecoration = TextDecoration.Underline),
)

Text(
    buildAnnotatedString {
        append("Open the ")
        withLink(LinkAnnotation.Url(url = "https://nockerl.dizyx.com", styles = linkStyles)) {
            append("docs site")   // UriHandler from the environment opens the URL
        }
    },
)
```

<Fragment slot="swift">

```swift
// macOS: SwiftUI (intended). Nockerl Voice ships no link component today (it opens
// system URLs via NSWorkspace and tints with NockerlTheme.accent); this is the
// intended link treatment: SwiftUI Link / markdown Text, the accent as tint.
import SwiftUI

// Standalone link.
Link("Open the docs site", destination: URL(string: "https://nockerl.dizyx.com")!)
    .tint(NockerlTheme.accent)            // brand cyan, the only link color
    .underline()

// Inline links inside prose come free from markdown; the tint sets the link color.
Text("Start in the [session console](nockerl://sessions) or read the [tokens](https://github.com/dizyx).")
    .tint(NockerlTheme.accent)
```

<DocCallout tone="warning" title="Cross-platform drift (tracked for reconciliation)">
The treatment is unified (cyan accent + underline); the implementations differ:

- **No shared link component yet.** Web documents the intended `@dizyx/nockerl-react`
  `Link`; **Android** has no `NockerlLink`, so links are markdown-rendered via
  `TextLinkStyles` / `LinkAnnotation`; **Swift/Voice** ships no link at all (it opens
  system URLs via `NSWorkspace`). All three should converge on one link spec.
- **Underline default.** Web + Swift underline at rest; the renderer's `TextLinkStyles`
  on Android should pin `TextDecoration.Underline` so links never read as plain accent text.
- **Link color token.** Bind every platform to the single accent (`accent.primary`), with no
  per-platform link hue.
</DocCallout>
