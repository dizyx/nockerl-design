The web console's **file explorer** is a deliberately THIN
SHELL that invents nothing: the forest is the shipped [`Tree`](/components/tree/)
(file-type tints, full WAI-ARIA keyboard semantics, controlled expand/select), the
header is an eyebrow title plus an **open `actions` slot** (drop
[`IconButton`](/components/icon-button/)s or a [`Menu`](/components/menu/) trigger in;
the shell owns no controls), and an empty forest renders the packaged recessed Well
with your message + optional action.

<DocCallout tone="note" title="Scope notes">
**Web-first chrome over a cross-platform core:** Compose + Swift already ship
`NockerlTree`; only this shell is console-specific. **Per-node context menus** stay with
the host for now: wiring `Menu` per row needs a Tree anchor extension, which is tracked
separately and is not shell scope.
</DocCallout>
