```kotlin
// Android: Jetpack Compose (canonical). The diff surface lives in chat/ui as
// DiffView, fed by the LCS computeLineDiff in chat/domain. It renders the file
// header, +/- gutter, and warm added/removed washes; split view is web-only.
import com.nockerl.app.chat.domain.DiffLine
import com.nockerl.app.chat.domain.DiffLineType
import com.nockerl.app.chat.domain.computeLineDiff

// computeLineDiff(old, new) → List<DiffLine>, each ADDED / REMOVED / UNCHANGED
// with a 1-based lineNumber. Pass old = "" for a new file (all-green additions).
val diffLines: List<DiffLine> = computeLineDiff(old = before, new = after)

// DiffView is internal to ToolCallCard.kt. It takes the path (for the header),
// the computed lines, and the resulting content (the copy button writes it):
DiffView(
    filePath = "app/.../net/Backoff.kt",
    diffLines = diffLines,
    newContent = after,
)
```

The header shows a `+N / -M` add/remove stat (warm status), each hunk gets an
`@@ -a,b +c,d @@` band, and a removed→added pair gets an **intra-line word
highlight** on the changed span. Added = `status.success` wash, removed =
`status.error` wash, context = muted, never the brand cyan, never color-alone.

<DocCallout tone="warning" title="Cross-platform drift (tracked for reconciliation)">
Sourced from the shipped Android `DiffView` + `computeLineDiff`; these are the real divergences:

- **Split view, hunk `@@` headers, `+N/-M` stats, intra-line word highlight, and
  collapse/expand** *(resolved)*: these are **web-only
  (documented)**. Android's `DiffView` stays a single unified column (one gutter, `+/-` prefix,
  warm washes); the richer affordances are the dedicated web viewer's, not a drift to reconcile.
- **Swift has no component.** Voice ships no diff (no tool-call surface). The web/Compose
  API is the target; Swift is queued.
- **Line numbers** *(resolved)*: line numbering **unifies on
  the dual `oldNo` / `newNo` shape** everywhere. Android (today one `DiffLine.lineNumber`) adopts
  the dual-number model the web `computeLineDiff` already carries.
- **Language pill:** there is no `file-type` token for **Swift**, so its pill falls back
  to a categorical violet. Add `file-type.swift` when Voice gains a real surface.
</DocCallout>
